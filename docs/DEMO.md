# 60-second agency demo

Prepare the local console, one clean sample, and a fresh discrepancy sample. Keep
the browser at normal desktop width. Clearly introduce fixture mode before recording.

| Time | Action | Suggested narration |
| --- | --- | --- |
| 0–10s | Show the register and run the discrepancy sample. | “This is an invoice-processing integration your agency can adapt for a client. These synthetic fixtures make the guardrails reproducible.” |
| 10–25s | Open total-field source evidence; page two appears. | “The extraction includes source references. Here the printed total is 1,300.” |
| 25–38s | Show the failed total check and review decision banner. | “Python calculates 1,250. That 50-dollar difference blocks automatic approval.” |
| 38–52s | Edit total, add a review note, approve; show audit trail. | “The operator resolves it. We retain both the original extraction and the correction.” |
| 52–60s | Show trace, then the clean record's automatic approval. | “The same API exposes status, checks, usage, and audit history. I can adapt this workflow to your client's system of record.” |

Do not describe model confidence as accuracy, fixture latency as live inference latency,
or zero fixture cost as a live processing quote. After configuring a real model, record
a separate upload with measured usage and keep the provider label visible.

Agency CTA: “Do you have a document-heavy client workflow where we could run a small,
fixed-scope integration trial?”
